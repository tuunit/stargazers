Stargazer History Visualizer

Load a stargazers JSON export to plot cumulative star growth over time.

Browser-only tool (no backend)

This HTML page runs entirely in your browser memory and does not have a backend server, so it cannot request stars directly from repository APIs. Instead, load a file generated via the gh command-line tool:

gh api -H 'Accept: application/vnd.github.v3.star+json' 'repos/{owner}/{repo}/stargazers?per_page=100' --paginate | jq '[.[] | {"starred_at": .starred_at, "user": .user.login}]' > stargazers.json
Choose a JSON file or drag & drop it here

Expected format: Array of objects with starred_at and user properties.
